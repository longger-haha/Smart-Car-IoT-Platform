# SmartRover 小车操作与巡航指南

## 一、系统架构

```
[ESP32固件] ←MQTT→ [Mosquitto] ←MQTT→ [后端Flask] ←HTTP→ [前端Vue]
   传感器/电机         消息代理        导航引擎/安全停车      控制面板
```

- **ESP32固件**：采集传感器数据（超声波、红外、温湿度、IMU、WiFi扫描），通过MQTT上报；接收后端下发的控制指令驱动电机；**本地实时避障（100ms级响应，含探路寻径）**
- **Mosquitto**：MQTT消息代理，负责上行遥测和下行指令的转发
- **后端Flask**：解密遥测数据入库，导航引擎根据传感器数据做避障/巡航决策，通过MQTT下发指令
- **前端Vue**：控制面板提供手动/自动控制，设备中心展示遥测数据和趋势图

---

## 二、手动控制模式

### 2.1 操作方式

控制面板 → 选择设备 → 手动模式 → 方向键

### 2.2 指令与电机行为

| 指令 | 动作 | 电机行为 |
|------|------|---------|
| `forward` | 前进 | 四轮正转，同速 |
| `backward` | 后退 | 四轮反转，同速 |
| `left` | 左转 | 左侧反转 + 右侧正转（原地旋转） |
| `right` | 右转 | 左侧正转 + 右侧反转（原地旋转） |
| `stop` | 停车 | 四轮停转 |

### 2.3 速度档位

| 档位 | PWM | 适用场景 |
|------|-----|---------|
| 低速 | 180 | 精确操控、窄空间 |
| 中速 | 200 | 日常驾驶（默认） |
| 高速 | 255 | 开阔直线 |

> **注意**：DC电机存在启动死区，PWM < 150 时电机只嗡嗡响不转。固件会自动将低于150的PWM提升到150。

### 2.4 安全保护

**双层安全机制**：

1. **ESP32本地避障（100ms级，最高优先级）**：每100ms读取超声波和红外，< 15cm紧急停车，15~30cm后退，30~50cm转向避障。本地避障激活时，后端下发的forward/diff等前进指令会被拦截
2. **后端安全停车（2秒级，兜底保护）**：超声波 < 15cm 时后端自动下发 `stop`，无论当前在做什么操作

## 三、自动巡航模式

### 3.1 自由巡航（仅避障）

无航点，小车持续直行，遇障碍自动避让。

**启动**：控制面板 → 自动巡航 → 启动巡航（不设航点）

**决策流程**（每2秒一次遥测 → 后端决策 → 下发指令）：

```
遥测数据到达
  ├─ 超声波 < 15cm → 紧急停车 (stop)
  ├─ 超声波 < 50cm 或 红外触发 → 避障绕行
  │   ├─ 左红外触发 → 右转绕行 (pwm_l=200, pwm_r=0)
  │   ├─ 右红外触发 → 左转绕行 (pwm_l=0, pwm_r=200)
  │   └─ 双侧触发 → 后退 (pwm_l=-200, pwm_r=-200)
  └─ 无障碍 → 直行 (pwm_l=pwm_r=巡航速度)
```

### 3.2 航点巡航

设2个以上航点，小车按航点顺序行驶。

**转向方式**：差速转向（不是原地旋转）

PID控制器根据目标方位角与当前航向的偏差，计算转向量 `steering`：

```
pwm_l = 巡航速度 - steering   (左轮减速 = 右转)
pwm_r = 巡航速度 + steering   (右轮减速 = 左转)
```

**PID参数**：

| 参数 | 值 | 作用 |
|------|-----|------|
| Kp | 2.5 | 比例增益，偏差越大转向越猛 |
| Ki | 0.02 | 积分增益，消除稳态偏差 |
| Kd | 0.8 | 微分增益，抑制振荡 |
| 输出限幅 | ±120 | 最大转向量，防止一侧PWM归零 |

**举例**：巡航速度200，目标方位偏右30°

- PID输出 steering ≈ +75
- pwm_l = 200 - 75 = 125 → 固件提升到150（最低阈值）
- pwm_r = 200 + 75 = 255
- 效果：右轮快、左轮慢 → 缓慢右转

**到达判定**：距航点 < 3m 即视为到达，切换下一航点。

### 3.3 巡航速度决定

| 来源 | 逻辑 |
|------|------|
| 前端档位 | 低速180 / 中速200 / 高速255 |
| 后端默认 | 200（前端未传时） |
| 航点巡航 | 使用启动时设定的速度，PID在此基础上加减转向量 |
| 避障绕行 | 固定200（不随档位变化） |
| 紧急后退 | 固定-200 |

## 四、差速转向详解

固件 `diffDrive(pwmL, pwmR)` 的行为：

| pwmL | pwmR | 效果 |
|------|------|------|
| +200 | +200 | 直行 |
| +200 | +100 | 右转（左快右慢） |
| +100 | +200 | 左转（左慢右快） |
| +200 | 0 | 大幅右转（左转右停） |
| 0 | +200 | 大幅左转（左停右转） |
| -200 | -200 | 后退 |
| +200 | -200 | 原地右转（原地旋转） |

**最低PWM阈值**：绝对值 < 150 自动提升到 150，防止电机只嗡嗡响不转。

**电机与轮子对应**：

| 电机 | 位置 | 侧别 |
|------|------|------|
| M1 | 右前 | 右侧 |
| M2 | 左前 | 左侧 |
| M3 | 左后 | 左侧 |
| M4 | 右后 | 右侧 |

- `pwmL` 控制 M2(左前) + M3(左后)
- `pwmR` 控制 M1(右前) + M4(右后)

## 五、安全机制

### 5.1 双层避障架构

| 层级 | 执行者 | 检查间隔 | 触发条件 | 动作 |
|------|--------|---------|---------|------|
| **L1 本地** | ESP32固件 | 100ms | 超声波 < 15cm | 紧急停车 |
| **L1 本地** | ESP32固件 | 100ms | 超声波 15~30cm | 后退1秒 → 转向 → 探路 |
| **L1 本地** | ESP32固件 | 100ms | 超声波 30~50cm | 转向0.8秒 → 探路 |
| **L2 后端** | Flask导航引擎 | 2秒 | 超声波 < 15cm | 下发stop（兜底） |
| **L2 后端** | Flask导航引擎 | 2秒 | 超声波 15~50cm + 巡航中 | 避障绕行 |

### 5.2 本地避障状态机

ESP32本地避障采用5状态有限状态机，确保避障动作有始有终，不会无限后退或死锁：

```
                    ┌─────────────────────────────────────────┐
                    │           AVOID_NONE (正常运行)           │
                    │  检查超声波, 仅motorRunning时生效         │
                    └──────┬──────────┬──────────┬────────────┘
                           │          │          │
                  < 15cm   │  15~30cm │  30~50cm │
                  紧急停车  │  后退     │  转向    │
                           │          │          │
                           ▼          ▼          ▼
              ┌──────────────┐ ┌──────────┐ ┌──────────┐
              │ AVOID_EMER   │ │AVOID_BACK│ │AVOID_TURN│◄────────┐
              │  停车等待     │ │ 后退1秒  │ │ 转向0.8秒│         │
              └──────┬───────┘ └────┬─────┘ └────┬─────┘         │
                     │              │            │               │
                     └──────────────┴────────────┘               │
                                    │                            │
                                    ▼                            │
                          ┌──────────────────┐                   │
                          │  AVOID_PROBE     │                   │
                          │  停车测距, 探路   │                   │
                          └──┬──────────┬────┘                   │
                             │          │                        │
                     前方>50cm│          │前方仍不安全             │
                     找到出路  │          │继续同方向转向───────────┘
                             │          │(最多重试6次≈360°)
                             ▼          │
                    ┌────────────┐      │
                    │ AVOID_NONE │      │
                    │ 恢复正常    │      │
                    └────────────┘      │
                             │          ▼
                    ┌────────┴───────┐  ┌──────────────┐
                    │ 巡航模式:       │  │ 重试6次仍无路 │
                    │ 自动恢复diff前进│  │ 放弃, 停车    │
                    │ 手动模式:       │  │ 等待人工指令   │
                    │ 停车等待指令    │  └──────────────┘
                    └────────────────┘
```

**状态说明**：

| 状态 | 触发条件 | 动作 | 最长持续时间 | 退出条件 |
|------|---------|------|------------|---------|
| AVOID_NONE | 正常运行 | 无 | - | 检测到障碍 |
| AVOID_EMERGENCY | 超声波 < 15cm | 立即停车 | 无限（等距离拉开） | 距离 > 30cm → 转向 |
| AVOID_BACKWARD | 超声波 15~30cm | 后退 PWM=-200 | 1秒 | 超时或距离 > 50cm → 转向 |
| AVOID_TURN | 后退后/中距离 | 原地转向 PWM=±200 | 0.8秒 | 超时 → 探路 |
| AVOID_PROBE | 转向完成后 | 停车测距 | 100ms（一次检查） | 前方安全→恢复；不安全→继续转 |

**探路机制（PROBE）**：

转向后不会盲目恢复前进，而是先停车用超声波确认前方距离：
- **前方 > 50cm**：找到出路，巡航模式自动恢复前进，手动模式停车等待
- **前方 ≤ 50cm**：继续同方向转向0.8秒，再次探路
- **重试6次仍无路**（约转了360度）：放弃，停车等待人工指令

**防止死锁**：
- 后退最多1秒，不会无限后退
- 转向+探路循环最多6次，覆盖360度
- 巡航模式恢复前进后如果又遇障碍，会重新进入避障流程（不会反复撞同一方向）

### 5.3 巡航模式自动恢复

避障完成后是否自动恢复取决于当前模式：

| 模式 | 避障完成后行为 | 原因 |
|------|--------------|------|
| **巡航模式**（收到过diff指令） | 自动恢复最后的diff指令前进 | 巡航需要持续运动 |
| **手动模式**（收到过forward等） | 停车等待新指令 | 手动模式由人决定 |

模式判定规则：
- 收到 `diff` 指令 → `inCruiseMode = true`，记录 `lastCruisePwmL/R`
- 收到 `forward/backward/left/right` → `inCruiseMode = false`
- 收到 `stop` → `inCruiseMode = false`，完全复位

### 5.4 本地避障指令拦截

当ESP32本地避障激活时（avoidState != AVOID_NONE）：
- **允许**：`stop`（立即停车）、`backward`（后退安全）
- **拦截**：`forward`、`left`、`right`、`diff`（前进方向不安全）

### 5.5 其他安全机制

| 条件 | 动作 | 生效模式 |
|------|------|---------|
| 红外触发 + 巡航中 | 避障绕行 | 仅自动巡航 |
| 电池 < 10V | 停车中止巡航 | 仅自动巡航 |
| 停止巡航按钮 | 立即停车，状态→IDLE | 自动巡航 |

## 六、延迟参数

| 环节 | 当前值 | 说明 |
|------|--------|------|
| **本地避障检查** | **100ms** | ESP32主循环读取传感器并决策 |
| **后端指令响应** | **~38ms** | 前端HTTP(30ms) + Flask缓存(2ms) + MQTT(5ms) + ESP32(1ms) |
| 遥测上报间隔 | 2秒 | 固件定时发送传感器数据 |
| 巡航指令间隔 | 0.3秒 | 后端决策→下发最小间隔 |
| MQTT QoS | 0 | 指令下发用QoS0（不等待确认） |
| 后端决策周期 | ~2.3秒 | 遥测间隔 + 指令间隔 |
| 设备归属缓存 | 60秒 | 后端内存缓存，避免每次查库 |

> **关键**：避障响应时间由本地100ms检查决定，不再依赖后端2秒遥测周期。手动指令端到端约38ms。

## 七、操作注意事项

1. **启动前**：确保小车悬空或放在安全位置，首次启动电机会自检
2. **手动控制**：点击方向键后小车会持续运动，需手动点"停止"
3. **切换模式**：手动→自动时，先停车再启动巡航；自动→手动时，先点"停止巡航"
4. **巡航安全**：建议用中速(200)，高速(255)在2秒决策周期下遇障可能来不及
5. **紧急停车**：ESP32本地避障100ms响应，超声波<15cm立即停车；后端2秒级兜底
6. **避障恢复**：巡航模式下避障后自动恢复前进；手动模式下停车等人；被包围时（360度无路）停车等人
7. **数据加密**：当前使用PLAIN明文模式（临时），AES加密修复后需切换回加密模式

## 八、MQTT通信协议

### 8.1 上行（固件→后端）

- **Topic**: `sensor/{device_id}`
- **格式**: `PLAIN:{JSON}` 或 `AES:{base64_iv}:{base64_ciphertext}`
- **间隔**: 2秒
- **内容**: 超声波、红外、温湿度、IMU、WiFi扫描、电池电压等

### 8.2 下行（后端→固件）

- **Topic**: `cmd/{device_id}`
- **格式**: JSON
- **QoS**: 0

**手动控制指令**：
```json
{"command": "forward", "speed_pwm": 200}
```

**差速指令**：
```json
{"cmd": "diff", "pwm_l": 200, "pwm_r": 100}
```

**停车指令**：
```json
{"command": "stop"}
```
