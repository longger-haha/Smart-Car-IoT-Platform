# ESP32 智能小车接线图（表格速查）

> **主控**: ESP32 DevKit (双核) | **电机驱动**: L293D 扩展板 (74HC595) | **电源**: 7.4V → LM2596(5V) + 3.3V 降压模块

---

## 一、电源系统接线

### 1.1 总电源分配

```
7.4V 锂电池组 ──┬── LM2596 降压模块 (→5.0V) ──┬── ESP32 5V/VIN
                │                             ├── L293D 扩展板 5V (逻辑)
                │                             └── HC-SR04 VCC
                ├── 3.3V 降压模块 (→3.3V) ──┬── MPU6050 VCC
                │                          ├── DHT11 VCC
                │                          ├── 红外左 VCC
                │                          └── 红外右 VCC
                └── L293D 扩展板 EXT_PWR (电机直连, 粗线)
```

### 1.2 LM2596 降压模块（电池 → 5.0V）

| LM2596 引脚 | 连接目标 | 线色 | 说明 |
|:---:|---------|:---:|------|
| IN+ | 电池正极 (红) | 🔴 | 输入 7.4V |
| IN- | 电池负极 (黑) | ⚫ | 输入地 |
| OUT+ | ESP32 5V/VIN + L293D 5V | 🔴 | ⚠️ 先调至 5.0V 再接 |
| OUT- | ESP32 GND + 共地 | ⚫ | 输出地 |

> ⚠️ 上电前用万用表确认 OUT+ 输出 **5.00V**（调蓝色电位器）

### 1.3 3.3V 降压模块（电池 → 3.3V）

| 模块引脚 | 连接目标 | 线色 | 说明 |
|:---:|---------|:---:|------|
| IN+ | 电池正极 | 🔴 | 输入 7.4V |
| IN- | 电池负极 | ⚫ | 输入地 |
| OUT+ | 传感器 VCC 总线 | 🔴 | MPU6050/DHT11/红外×2 |
| OUT- | ESP32 GND + 共地 | ⚫ | 输出地 |

> 💡 独立供电减轻 ESP32 板载 AMS1117-3.3（仅 600mA）压力

### 1.4 各部分供电汇总

| 供电来源 | 电压 | 用电设备 | 预估电流 |
|---------|:---:|---------|:---:|
| 电池直连 | 7.4V | L293D 驱动 4×电机 (EXT_PWR) | 最大 ~6A |
| LM2596 → 5V | 5.0V | ESP32 + HC-SR04 + L293D 逻辑 | ~500mA |
| 3.3V 降压模块 | 3.3V | MPU6050 + DHT11 + 红外×2 | ~50mA |

## 二、MPU6050 六轴陀螺仪

| MPU6050 引脚 | 连接目标 | 线色 | 说明 |
|:---:|---------|:---:|------|
| VCC | 3.3V 降压模块 OUT+ | 🔴 | ⚠️ 只能 3.3V，接 5V 会烧！ |
| GND | ESP32 GND + 共地 | ⚫ | |
| SCL | ESP32 **GPIO22** | 🟡 | I²C 时钟线 |
| SDA | ESP32 **GPIO21** | 🟢 | I²C 数据线 |
| AD0 | GND | ⚫ | 地址 = 0x68 |
| INT | 不接 | - | 本项目未使用 |

> ⚠️ SCL→GPIO22，SDA→GPIO21，接反后 I²C 扫描不到设备

## 三、HC-SR04 超声波传感器

| HC-SR04 引脚 | 连接目标 | 线色 | 说明 |
|:---:|---------|:---:|------|
| VCC | ESP32 **5V** | 🔴 | ⚠️ 必须 5V！3.3V 不稳 |
| Trig | ESP32 **GPIO25** | 🟠 | ≥10μs 高脉冲触发 |
| Echo | ESP32 **GPIO26** | 🟣 | 高电平脉宽/58 = 距离(cm) |
| GND | ESP32 GND + 共地 | ⚫ | |

> 距离公式：`cm = pulseIn(Echo, HIGH, 30000) / 58`

## 六、L293D 电机驱动扩展板

### 6.1 74HC595 控制引脚（4 根跳线）

| 扩展板引脚 | 功能 | ESP32 GPIO | 方向 | 说明 |
|:---:|------|:---:|:---:|------|
| D12 | LATCH (锁存) | **GPIO5** | → | 上升沿锁存 74HC595 |
| D4 | CLOCK (时钟) | **GPIO18** | → | 上升沿移入 1 bit |
| D7 | ENABLE (使能) | **GPIO23** | → | ⚠️ LOW=启用, HIGH=全停 |
| D8 | DATA (数据) | **GPIO13** | → | MSB 优先，串行写入 |

### 6.2 PWM 电机控制引脚（4 根跳线）

| 扩展板 | 电机 | 轮位 | ESP32 GPIO | LEDC 通道 | PWM 范围 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| D11 | M1 | 右前 RF | **GPIO4** | 0 | 0~255 |
| D3 | M2 | 左前 LF | **GPIO16** | 1 | 0~255 |
| D6 | M3 | 左后 LB | **GPIO17** | 2 | 0~255 |
| D5 | M4 | 右后 RB | **GPIO19** | 3 | 0~255 |

### 6.3 扩展板电源连接

| 扩展板端子 | 连接目标 | 线规 | 说明 |
|:---:|---------|:---:|------|
| 5V | LM2596 OUT+ (5V) | 杜邦线 | 芯片逻辑电源 |
| GND | 共地 | 杜邦线 | 逻辑地 |
| EXT_PWR (+) | 电池正极 (红) | ⚠️ 粗线 AWG20+ | ⚡ 电机独立供电 |
| EXT_GND (-) | 电池负极 (黑) | ⚠️ 粗线 AWG20+ | ⚡ 电机地 |

> ⚠️ EXT_PWR 不接 = 电机不转；5V 不接 = 芯片不工作  
> ⚠️ 电机电源务必用粗线，杜邦线大电流会发热

### 6.4 74HC595 位映射

| Bit | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 功能 | M3_B | M4_B | M3_A | M2_B | M1_B | M1_A | M2_A | M4_A |
| 电机 | 左后 | 右后 | 左后 | 左前 | 右前 | 右前 | 左前 | 右后 |
| 方向 | 反转 | 反转 | 正转 | 反转 | 反转 | 正转 | 正转 | 正转 |

| 电机 | 轮位 | GPIO(PWM) | 正转位 | 正转值 | 反转位 | 反转值 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| M1 | 右前 RF | GPIO4 | Bit2 | 0x04 | Bit3 | 0x08 |
| M2 | 左前 LF | GPIO16 | Bit1 | 0x02 | Bit4 | 0x10 |
| M3 | 左后 LB | GPIO17 | Bit5 | 0x20 | Bit7 | 0x80 |
| M4 | 右后 RB | GPIO19 | Bit0 | 0x01 | Bit6 | 0x40 |

| 组合 | 位值 | 十六进制 |
|------|------|:---:|
| 四轮全正转 | Bit0+1+2+5 | 0x27 |
| 四轮全反转 | Bit3+4+6+7 | 0xD8 |
| 原地左转 (左反右正) | Bit0+2+4 | 0x15 |
| 原地右转 (左正右反) | Bit1+3+5 | 0x2A |

### 6.5 电机控制逻辑

| 动作 | 正转位 | 反转位 | PWM | 效果 |
|:---:|:---:|:---:|:---:|------|
| 正转 | 1 | 0 | 1~255 | 轮子前进 |
| 反转 | 0 | 1 | 1~255 | 轮子后退 |
| 停止 | 0 | 0 | 0 | 惯性滑行 |
| 刹车 | 1 | 1 | 0 | 电子刹车 |

### 6.6 电机端子接线

| 端子 | 标记 | 轮位 | 接法 |
|:---:|:---:|------|------|
| M1 | + / - | 右前 RF | 红/黑 |
| M2 | + / - | 左前 LF | 红/黑 |
| M3 | + / - | 左后 LB | 红/黑 |
| M4 | + / - | 右后 RB | 红/黑 |

> 💡 某电机方向反了 → 对调该端子的 + - 接线即可

### 7.2 线色编码建议

| 颜色 | 用途 | 典型数量 |

### 7.3 禁用引脚

| GPIO | 原因 | 后果 |
|:---:|------|------|
| GPIO0 | Strapping (BOOT 按钮) | 启动异常 |
| GPIO2 | 板载 LED + Strapping | 启动异常 |
| GPIO12 | Flash 电压选择 | ⚠️ 严禁使用 |
| GPIO15 | Strapping (静默启动) | 启动异常 |
| GPIO34-39 | 仅输入 | 不可做 PWM/输出 |

## 九、差速驱动速查

| pwmL (左) | pwmR (右) | 运动效果 | 用途 |
|:---:|:---:|:---:|------|
| 200 | 200 | ⬆️ 直行 | 巡航前进 |
| 180 | 180 | ⬆️ 低速直行 | 低速巡航 |
| 255 | 255 | ⬆️ 全速直行 | 竞速模式 |
| 200 | 100 | ↱ 右转 | 右弯 |
| 100 | 200 | ↰ 左转 | 左弯 |
| 200 | -200 | ↻ 原地右转 | 避障转向 |
| -200 | 200 | ↺ 原地左转 | 避障转向 |
| -200 | -200 | ⬇️ 后退 | 避障后退 |
| 0 | 0 | ⏸ 停止 | 停车 |

> DC 电机启动死区：PWM < 150 自动提至 150  
> pwmL 控制 M2(左前)+M3(左后)，pwmR 控制 M1(右前)+M4(右后)
